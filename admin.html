Actualizar stock del catálogo

Acceso de administración

Para publicar, esta página necesita una clave de GitHub con permiso solo sobre el catálogo. Se pide una vez y queda guardada en este navegador.

  1. Entrá a github.com → Settings → Fine-grained tokens → Generate new token con la cuenta RodryR22.
  2. Nombre: Stock catálogo HK. Vencimiento: el que prefieras (por ejemplo 1 año).
  3. Repository access: Only select repositories → catalogo-hk.
  4. Permissions → Repository permissions → Contents: Read and write. Nada más.
  5. Generá la clave, copiala y pegala acá.

1 Cargar los archivos de stock

Los dos archivos de Gestión: STOCK_REPRE.xls y STOCK_AUTOCENTRO.xls (carpeta «STOCK GENERAL REPRESENTACIONES»). Se leen en esta computadora; las cantidades no se publican.
